# Возобновление загрузок Fedstat

`update_realty.py` передаёт Fedstat идентификатор общего запуска. После каждого
успешно проверенного или скачанного показателя `fedstat_checker.py` атомарно
записывает receipt в `state/fedstat_run_checkpoint.json`. Поэтому повтор
источника после watchdog пропускает уже завершённые показатели этого запуска.

Части выгрузки 34118 сохраняются в
`downloads/.fedstat_resume/<indicator>/<payload-hash>/`. Hash включает дату
публикации и полный набор фильтров. При следующем процессе валидные части
переиспользуются, а повреждённые скачиваются заново. Готовый итоговый Excel
по-прежнему создаётся атомарно и только после проверки всех частей.

Основной transport — multipart POST с новым CSRF-токеном. Это тот вариант,
который успешно отвечал Excel в рабочих логах. Для chunk-запросов после 503 или
HTML выполняется короткий повтор самого chunk; медленные SDMX и browser fallback
не запускаются. Для обычных цельных выгрузок прежние fallback сохранены.
