# Fedstat: набор для текущего дашборда

Обычный запуск `python fedstat_checker.py`, `update.bat fedstat` и этап
Fedstat в `update.bat` проверяют **6 источников вместо 30**. Остальные 24
сборщика сохранены, но отключены по умолчанию. Старые Excel, квитанции загрузок
и записи state не удаляются. `--force` перекачивает только выбранный набор,
не включает остальные сборщики.

Единственное место настройки набора по умолчанию — `DEFAULT_INDICATOR_USAGE`
в `fedstat_checker.py`. Полный каталог имён и доступных сборщиков —
`INDICATORS` в том же файле. Порядок проверки: зарплата, ИПЦ, затем тяжёлый
ввод жилья 34118. В журнале до запуска браузера перечисляются активные и
отключённые ID с количеством; при точечном запуске отдельно виден фильтр.

Аудит охватывает страницы `app/pages`, `app/shared` и
`pipeline/data_access.py`, а не только `pipeline/registry.py`: ввод жилья
читает Excel напрямую и отсутствует среди Fedstat-показателей registry.
Страница «ВРП и ВВП» через `load_national_accounts` использует показатели
Росстата/Мосстата и производные данные, а не одноимённые сборщики Fedstat.
Совпадение слов в имени файла или наличие готового сборщика само по себе
не означает использования в визуализации.

## Как включить позже

Разово запросить любой известный сборщик, включая отключённый:

```bat
python fedstat_checker.py --only=33648,61497
python fedstat_checker.py --only=33648 --force
```

Для запуска через Windows-обёртку можно задать переменную в текущем `cmd`:

```bat
set "FEDSTAT_ONLY_IDS=33648,61497"
update.bat fedstat
set "FEDSTAT_ONLY_IDS="
```

`--only=` имеет приоритет над непустой переменной окружения. Выбор заменяет
набор по умолчанию, а не добавляет к нему. Псевдонимы `31074` и `34118`
разворачиваются в обе части. Неизвестный ID отменяет весь запуск с кодом 2
до открытия браузера и записи state. Ошибка ID в конфигурации набора по
умолчанию также останавливает запуск, чтобы не скрыть потерю источника.

Для постоянного включения после появления новой визуализации добавьте ID и
описание её потребителя в `DEFAULT_INDICATOR_USAGE`, затем обновите проверку
потребителей в `scripts/check_fedstat_scope.py` и эту таблицу. Логику экспорта
восстанавливать не требуется: все 30 сборщиков остаются в коде.

## Проверка

`python scripts/check_fedstat_scope.py` проверяет набор и порядок, `--force`,
неизменившиеся даты, включение отключённых ID через CLI/окружение, обе части
псевдонимов, отказ при неизвестном ID, частичные ошибки, сохранность старых
записей state и квитанции только успешных загрузок. Браузер и сеть подменены;
запись идёт только во временный каталог. Проверка подключена к
`scripts/validate_realty_dashboard.bat`.

Это сокращает лишнюю работу, но не исправляет доступность Fedstat. Обе части
34118 остаются активны: они нужны странице ввода, и их ошибки по-прежнему
означают незавершённое обновление. Изменение набора не запускает загрузки;
ИПЦ и production-данные при разработке повторно не скачиваются.
