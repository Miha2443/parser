# Даты скачивания в экономических разделах

`loaded_at` в парсере ИПЦ означает время обработки Excel. Повторная сборка
старого файла меняла надпись «Обновлено» на сегодняшнюю дату. Дата в имени
выгрузки Fedstat также не подходит: это дата обновления на сайте.

ИПЦ, зарплаты, национальные счета и карточки главной страницы теперь показывают
даты исходных файлов, названных в `source_file` отображаемой витрины.
Новый файл с другим именем не может сделать старую витрину визуально свежей.
В таблице по каждому файлу показаны путь, подтверждённая дата скачивания,
время изменения файла и последний период данных. Часовой пояс — Москва.

Для прежних файлов без истории дата скачивания честно остаётся неизвестной.
Время изменения локального файла явно подписано как «Дата файла»; это не
доказательство скачивания. Отсутствующий исходник также показывается явно.

Каждый успешный возврат `fedstat_checker.download_excel`, включая fallback,
теперь записывает квитанцию в `.download_receipts/<имя файла>.json` внутри
каталога исходников. Она содержит время завершения скачивания в UTC,
SHA-256, ID источника и отдельную дату публикации. Каталог скрытых квитанций
не попадает в обычные ETL-паттерны `*.xls*`. Ошибка скачивания не создаёт
и не обновляет квитанцию; пропуск неизменившегося источника не вызывает
скачивание и тоже сохраняет прежнюю дату.

Дата считается подтверждённой только при совпадении SHA-256 квитанции и
текущего файла. Если подтверждённое скачивание произошло после обработки
витрины, показывается «требуется ETL». Исторические витрины не хранят хеш
исходника: сравнение с временем обработки служит ограниченной проверкой,
а не доказательством побайтового соответствия старой витрине.

Офлайн-проверка `python -B scripts/check_download_provenance.py`: 8 тестов
на старый файл после новой обработки, дату из квитанции, подмену содержимого,
не относящийся к витрине новый файл, потерянный исходник, разные части ИПЦ,
повреждённую квитанцию и успешный/неудачный возврат загрузчика. Все файлы
проверки создаются во временном каталоге. Проверка добавлена в
`scripts/validate_realty_dashboard.bat` с сохранением CRLF.

Изменение не скачивает новые данные и не устраняет сетевые ошибки Fedstat.
Production-данные, state и исторические логи не пересобирались и не менялись.
