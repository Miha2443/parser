переносе. Эта таблица фиксирует границы, а не подтверждает приёмку новых страниц.

## Источники профиля

- Мониторинг 2.0: действующий общий loader РВ (включая лист 4) и ОКС;
  категории площадей, ввод по годам, объекты.
- ERZRF top: рейтинги по строительству и накопленному вводу, Москва/РФ.
- ERZRF cards: сданное жильё и переносы по годам, сопоставления Москва/другие регионы.
- Распроданность: по выбранной компании, отчётный период, продажи и стройготовность.
- Квартирография: региональные данные компании по комнатности, числу и площади квартир.
- Эскроу: кредитные лимиты и наполнение по Москве, текущие правила нормализации компании.

Фильтр региона квартирографии не должен менять московские показатели мониторинга.
Московские показатели в новом профиле обозначаются явно.

## Границы первого визуального этапа

В новом интерфейсе доступен профиль нескольких компаний на фиксированном срезе.
Срез пересобирается отдельным скриптом; он не является автоматическим обновлением.
Другие разделы открываются в действующем Streamlit, пока не перенесены.
Проверка полного соответствия API и Excel-экспорта выполняется после согласования
визуала. Контрольные цифры и происхождение среза описаны в `dashboard-baseline.md`.
